# Valorant-Ultrawide-Fix
A simple open source program that fixes a problem that valorant has with ultrawide monitors. Read the README for more info.

# Settings
For this program to work, you need to have your resolution set to your monitor, (not your native resoultion, just whatever resolution your monitor is currently on).
you need to be on windowed, and fill. Once your windowed screen is "full screen" taking up all the space on your desktop, press the "Remove Title Bar & Fit" button, leave "Keep applying while Valorant is open" unchecked.

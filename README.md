# Valorant-Ultrawide-Fix
A simple open source program that fixes a problem that valorant has with ultrawide monitors. Read the README for more info.

# Settings
Step 1. make sure your on windowed
Step 2. the resolution needs to be your desktop resolution (for the full screen feel.)
Step 3. Make sure your on fill, then press "Remove Title Bar & Fit"
Also, leave "Keep applying while Valorant is open" unchecked.
